# Dart-Vader-A-Semi-Autonomous-Nerf-Turret
Dart Vader is a nerf turret which has object tracking capabilities, along with manual control. I wanted to build this project because I don't like when my sister walks into my room and bothers me, so now I can shoot her with a nerf dart if she comes into my room!

## The Project
Dart Vader is a passion project I have wanted to build for a while, and now I am building it as part of hackclub Torque. It is a standalone turret that uses a raspberry pi camera to identify and track objects, and uses a custom nerf-style flywheel setup to launch nerf darts at the target.
